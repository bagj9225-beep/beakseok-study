# 백석고 경제·정치 학습

기말고사 대비 학습 웹앱이에요. 개념 카드, OX 퀴즈, 심화 5지선다, 오답 복습이 있어요.

## 실행 방법
`index.html`을 더블클릭하면 안 열려요. 브라우저가 JSON 파일 읽기를 막기 때문이에요.

- **내 컴퓨터에서**: 이 폴더에서 터미널을 열고 `python3 -m http.server 8000`을 입력한 뒤, 브라우저에서 `http://localhost:8000`에 들어가요.
- **폰에서**: GitHub Pages 주소로 들어가요.

## 콘텐츠 바꾸기
- `data/` 폴더의 JSON 파일을 같은 이름으로 덮어써요. 파일 목록은 `js/config.js`에 있어요.
- 형식과 단원 이름 규칙은 `CLAUDE.md`의 "콘텐츠 JSON 형식"을 봐요.
- 넣은 뒤에는 설정 → 개발용 도구 → 콘텐츠 검사에서 "문제 없음"인지 확인해요.
- 지금 개념 카드는 임시 카드예요. 팀 카드로 바꿀 예정이에요.
