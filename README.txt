[백석고 경제·정치 학습 웹앱] 1단계: 뼈대 + 샘플 데이터 불러오기

■ 폴더 구조
  index.html   화면 뼈대
  css/         디자인 (색·크기는 style.css 맨 위 변수에서 바꿔요)
  js/          config.js(파일 목록·설정) / data.js(불러오기·검수) / app.js(화면)
  data/        콘텐츠 JSON (지금은 샘플. 친구들 파일로 같은 이름으로 덮어쓰면 돼요)

■ 실행 방법 (index.html 더블클릭은 안 돼요. 브라우저가 JSON 읽기를 막아요)
  방법 A) 컴퓨터에서 임시 서버: 이 폴더에서 터미널을 열고
          python3 -m http.server 8000
          브라우저에서 http://localhost:8000 접속
  방법 B) GitHub Pages 등에 올려서 주소로 열기

■ 1단계 확인
  - 불러오기 성공 이 보이고 파일 4개 카드가 나오면 통과
  - 친구들 JSON을 넣었을 때 문제 목록(ID 중복, 없는 개념 id 등)이 나오면 검수 기능도 작동 중
  - 샘플 데이터는 테스트용이므로 실제 시험 내용으로 쓰지 마세요
